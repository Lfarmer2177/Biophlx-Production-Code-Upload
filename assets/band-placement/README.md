# BIOPHLX placement photos

These six PNG assets are extracted photo regions from the user-provided BIOPHLX-Light-and-Dark.pdf, pages 1 (light) and 2 (dark). No new person or sensor placement was generated. App usage was requested by the user on 2026-09-19.

Arms: one sensor on each upper arm. Legs: one sensor on each thigh. Combined: the source shows the wearer's right upper arm and right thigh; the app mirrors only the Image when left-side placement is selected. Captions stay readable and follow placementSlots band assignments. Assets are bundled locally for offline display.
